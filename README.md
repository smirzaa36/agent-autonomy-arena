# Agent Autonomy Arena

An interactive classroom simulator for exploring agent autonomy, permissions, and human approval.

## Overview

Choose a mission, adjust the priorities that matter to you, and compare agent profiles to see which profile is the best fit. The interface also lets you inspect the access associated with each profile before making a decision.

## What you can explore

- Select a mission, such as study research, code-repository review, drafting an instructor email, or handling a payment request.
- Adjust priorities including safety and human approval, and speed and convenience.
- Compare ranked agent profiles and their fit scores.
- Inspect each profile's access and permission details.
- Sort profiles by safety fit.
- Save a comparison and review or clear saved comparisons.
- Switch between dark and light themes.

## How to run

1. Download `agent-autonomy-arena.html`.
2. Open the file in a modern web browser.
3. Use the controls on the page to change the mission and priorities.

No installation or build step is required.

## Note

The page describes its scores as a transparent classroom simulation, not a real-world benchmark. Use the scores for learning and comparison within the simulator, not as a measure of actual agent performance.
